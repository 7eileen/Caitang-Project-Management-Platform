彩棠工作台项目管理 · 汇报演示版

打开方式
双击「彩棠项目驾驶舱.html」，使用 Chrome 或 Edge 浏览器打开，无需联网。

汇报路径
1. 项目总览：查看阶段完成率、甘特图、里程碑及进行中的细分计划。
2. 点击任一阶段进入阶段计划。通过原表分组、状态或名称筛选计划，点击查看用时和日期。
3. 右上角全屏按钮适合投屏汇报。

每周更新
细分计划：上传原结构的「集团流程改革-彩棠试点项目工作计划.xlsx」。
总阶段：在数据更新页下载 CSV 模板，维护五个阶段的日期和状态后导入。
先预览差异、填写报告基准日期，再确认更新。
导入只在当前页面生效，点击「导出汇报版」保存含最新数据的独立 HTML 文件，或导出 JSON 快照。
原 Excel 不会被改写；此版本不提供多人在线同步。

数据口径
五个阶段按用户管理总表：启动、规划阶段、调研阶段、详细设计阶段、实施落地阶段。
年份按 Excel 的 2026 年；初始报告基准为 2026-09-29，不代表原表采集日期。
细分内容只读取第一张「项目计划」，不读取另外两张表。共39条记录，其中3条分组标题、36条细分计划项。
总阶段筛选：架构规划归入规划阶段，需求调研归入调研阶段，功能需求、新审批流和项目看板设计归入详细设计，其余归入实施落地。
保留原表用时与原始状态，未填日期与状态不作推算。周视图为以报告基准日期为中心的6周放大窗口。
