彩棠工作台项目管理

打开方式
双击「彩棠项目驾驶舱.html」，使用 Chrome 或 Edge 浏览器打开，无需联网。

汇报路径
1. 项目总览：查看六阶段完成率、计划与实际甘特图、里程碑及当前项目卡点中的关键结论。
2. 阶段计划：按「阶段 → 一级任务 → 二级任务」查看，支持逐级折叠、名称搜索、任务与状态筛选。
3. 表格把四个日期字段合并为「计划周期」「实际周期」，以「08.04 — 08.11」格式呈现，原始日期保持不变；点击任务可查看详情，或切换计划甘特。
4. 右上角全屏按钮适合投屏汇报。

每周更新
上传新版「彩棠工作台项目进度表.xlsx」，保留八列表头及层级结构，同时更新总览与详细计划。
八列为：名称、主责部门、层级、计划开始时间、计划结束时间、实际开始时间、实际结束时间、阶段状态。
仍兼容旧版「项目计划」Excel、与当前阶段结构一致的阶段更新 CSV，以及导出的 JSON 快照。
先预览差异、填写报告基准日期，再确认更新。
确认导入后自动保存当前看板、更新记录和原文件；刷新后会恢复最近一次更新。
更新记录仅提供「下载原文件」，可下载新版进度表、最初上传的 Excel 及每次确认导入的原文件。
记录保存在当前浏览器中，清除网站数据、更换浏览器或设备后不会同步保留。
旧版浏览器记录会继续保留，但旧版缓存不会覆盖此次新版默认数据。
点击「导出汇报版」另存当前看板；离线 HTML 包含新版和初始 Excel 原件，不包含全部历史上传文件。
导出的 JSON 可用于保存和重新导入看板数据。
原 Excel 不会被改写；此版本不提供多人在线同步。

数据口径
当前默认数据来自「彩棠工作台项目进度表.xlsx」的 Sheet1。
六阶段：启动、规划阶段、调研阶段、详细设计阶段、实施落地阶段、上线试运行。
表中共 55 条阶段与任务记录：6 个阶段、6 个一级任务、43 个二级任务。
细分计划指标只统计无子项的 45 个任务，避免父子任务重复计数；当前 21 项已完成、5 项进行中、19 项未开始。
总览 3/6 阶段已完成，阶段完成率 50%。项目计划周期为 2026.08.03—2026.12.10。
日期、状态均保留原表内容。斜杠「/」保持原样，空白不作推算，也不根据今天的日期改写任务状态。
「新审批流设计」实际日期 10.08—10.16、状态「进行中」均按原表展示。
表尾两条不上线事项置于「当前项目卡点」，标为「关键结论」。
计划与实际甘特条叠加于同一行，通过透明度区分。日期分别置于浅色计划条、深色实际条，日期重叠时前后并列排列，色条过短时在相邻空白处同排展示。
周视图为当天附近的 6 周放大窗口。「今天」标线按北京时间自动移动，跨天及切回页面时自动更新。
年份按 Excel 的 2026 年；初始报告基准为 2026-09-29，不代表原表采集日期。
