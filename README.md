# 彩棠工作台项目管理

集团流程改革彩棠试点项目看板，包含项目总览、细分阶段计划和每周数据更新。

## 使用

- **离线汇报**：下载 [`downloads/彩棠项目驾驶舱.html`](downloads/彩棠项目驾驶舱.html)，使用 Chrome 或 Edge 双击打开，无需联网。
- **运行源码**：在仓库目录执行 `python -m http.server 8765`，访问 `http://localhost:8765`。
- **发布前构建**：使用 Python 3 执行 `python scripts/build_offline.py`。脚本按文件内容更新在线资源版本号，避免浏览器沿用旧脚本，同时在 `downloads/` 生成离线版。

## 页面内容

- 项目总览：五个管理阶段的甘特图、完成状态、里程碑和当前项目卡点（目前暂无卡点）。
- 阶段计划：原表顺序与分组、搜索和状态筛选、分组折叠、16 周计划甘特与详情。
- 数据更新：导入 Excel、阶段更新 CSV 或 JSON 快照，预览差异后确认，自动保存更新记录与原文件，支持下载每次上传的原文件和导出包含最新数据的独立 HTML。

总管理阶段固定为：启动、规划阶段、调研阶段、详细设计阶段、实施落地阶段。总览月视图呈现完整周期，周视图放大当天附近的六周。甘特图「今天」标线按北京时间自动移动，页面跨天保持打开、切回页面或电脑唤醒后也会更新；报告基准、计划日期与任务状态仍保留上传数据。

## 数据范围

内置数据来自用户提供的总管理阶段截图，以及 Excel **第一张「项目计划」**。看板细分数据只读取这一张表；供下载的 Excel 原件完整保留原工作簿，不改写其他工作表。细分表有 39 条记录，其中 3 条为分组标题、36 条为计划项；页面将两个长分组名称简化为「需求评审」和「实施开发」。原始用时和状态保留，未填日期不作推算。

初始报告基准为 2026-09-29，项目年份按原表的 2026 年设置。

## 每周更新

1. 在原 Excel 的「项目计划」工作表更新用时、日期范围和状态，保留工作表名称与原有列顺序。
2. 在页面上传 Excel，检查变更和报告基准日期后确认。导入器只读取「项目计划」。
3. 如需更新五个管理阶段，导入符合五个管理阶段结构的 CSV。
4. 确认导入后，当前看板、当次计划快照及原文件会一起保存到浏览器 IndexedDB，刷新会恢复最近一次更新。未确认、取消、解析失败或存储失败的导入不写入历史。
5. 在「更新记录」下载当次上传的原文件。初始记录提供最初上传的 Excel 原件，不再提供网页预览或 JSON 快照下载按钮。
6. 点击「导出汇报版」或导出 JSON 可另存当前看板数据；导出文件保留初始 Excel 原件，但不携带全部历史上传文件。

记录仅保存在创建记录的浏览器和网站地址下；清除网站数据、更换浏览器或设备不会同步保留。每个离线 HTML 文件的记录也独立保存。本版本不提供多人同步、服务端存储或外部 AI 服务。详细操作见 [`docs/使用说明.txt`](docs/使用说明.txt)。

## 文件

| 文件 | 用途 |
| --- | --- |
| `index.html` | 页面入口 |
| `style.css` | 页面样式 |
| `app.js` | 交互、Excel 读取、导入和导出 |
| `data.js` | 初始项目数据 |
| `original-excel.js` | 初始 Excel 原件的无损内嵌数据，用于在线与离线下载 |
| `downloads/彩棠项目驾驶舱.html` | 可直接打开的离线版 |
| `scripts/build_offline.py` | 无第三方依赖的离线打包脚本 |

Excel 解压使用 Pako，MIT 许可声明保留在 `app.js` 中。

## 验证

`tests/history.spec.cjs` 覆盖旧脚本缓存下的新版本加载、导入确认、刷新恢复、初始与历史 Excel 原文件下载一致性、取消与无效文件、存储失败，以及离线导出后的导入记录。需要 Node.js、Playwright 和 Microsoft Edge；安装 Playwright 后运行 `node --test tests/history.spec.cjs`。测试使用隔离浏览器及合成 Excel，不写入日常使用的浏览器记录。
