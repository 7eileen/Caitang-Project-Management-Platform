# 彩棠工作台项目管理

集团流程改革彩棠试点项目看板，包含项目总览、细分阶段计划和每周数据更新。

## 使用

- **离线汇报**：下载 [`downloads/彩棠项目驾驶舱.html`](downloads/彩棠项目驾驶舱.html)，使用 Chrome 或 Edge 双击打开，无需联网。
- **运行源码**：在仓库目录执行 `python -m http.server 8765`，访问 `http://localhost:8765`。
- **重新生成离线版**：使用 Python 3 执行 `python scripts/build_offline.py`，生成文件位于 `downloads/`。

## 页面内容

- 项目总览：五个管理阶段的甘特图、完成状态、里程碑和进行中的细分计划。
- 阶段计划：原表顺序与分组、搜索和状态筛选、分组折叠、16 周计划甘特与详情。
- 数据更新：导入 Excel、阶段更新 CSV 或 JSON 快照，预览差异后确认，支持导出包含最新数据的独立 HTML。

总管理阶段固定为：启动、规划阶段、调研阶段、详细设计阶段、实施落地阶段。总览月视图呈现完整周期，周视图放大报告基准附近的六周。

## 数据范围

内置数据来自用户提供的总管理阶段截图，以及 Excel **第一张「项目计划」**。不包含其他工作表。细分表有 39 条记录，其中 3 条为分组标题、36 条为计划项；页面将两个长分组名称简化为「需求评审」和「实施开发」。原始用时和状态保留，未填日期不作推算。

初始报告基准为 2026-09-29，项目年份按原表的 2026 年设置。

## 每周更新

1. 在原 Excel 的「项目计划」工作表更新用时、日期范围和状态，保留工作表名称与原有列顺序。
2. 在页面上传 Excel，检查变更和报告基准日期后确认。导入器只读取「项目计划」。
3. 如需更新五个管理阶段，在更新页下载并填写阶段 CSV 模板后导入。
4. 点击「导出汇报版」或导出 JSON 快照，保存本周版本。页面刷新前请保存最新数据。

本版本在浏览器本地处理导入数据，不提供多人同步、服务端存储或外部 AI 服务。详细操作见 [`docs/使用说明.txt`](docs/使用说明.txt)。
