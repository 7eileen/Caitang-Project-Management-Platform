# 彩棠工作台项目管理

集团流程改革彩棠试点项目看板，包含项目总览、细分阶段计划和每周数据更新。

## 使用

- **离线汇报**：下载 [`downloads/彩棠项目驾驶舱.html`](downloads/彩棠项目驾驶舱.html)，使用 Chrome 或 Edge 双击打开，无需联网。
- **运行源码**：在仓库目录执行 `python -m http.server 8765`，访问 `http://localhost:8765`。
- **发布前构建**：使用 Python 3 执行 `python scripts/build_offline.py`。脚本按文件内容更新在线资源版本号，避免浏览器沿用旧脚本，同时在 `downloads/` 生成离线版。

## 页面内容

- 项目总览：六个管理阶段的甘特图、完成状态、里程碑和当前卡点和关键结论中的关键结论。里程碑按计划结束日期排序，显示报告基准日期起的节点；有一级任务的阶段使用一级任务，没有一级任务的使用阶段，避免重复列出父阶段。
- 阶段计划：按「阶段 → 一级任务 → 二级任务」展示，保留原表顺序和状态，四个日期字段在页面合并为「计划周期」「实际周期」两列；支持搜索、筛选、逐级折叠、计划甘特与详情。
- 数据更新：导入 Excel、阶段更新 CSV 或 JSON 快照，预览差异后确认，自动保存更新记录与原文件，支持下载每次上传的原文件和导出包含最新数据的独立 HTML。

总管理阶段为：启动、规划阶段、调研阶段、详细设计阶段、实施落地阶段、上线试运行。甘特图将计划与实际周期叠加在同一行，保留原配色与圆角色条，通过透明度区分计划与实际，不显示轮廓线；计划日期标在浅色部分，实际日期标在深色部分，相同或相交时间段的日期横向并列排列，过短色条的日期在邻近空白处同排展示，避免重叠。总览月视图呈现完整周期，周视图放大当天附近的六周。甘特图「今天」标线按北京时间自动移动，页面跨天保持打开、切回页面或电脑唤醒后也会更新；报告基准、计划日期与任务状态仍保留上传数据。

## 数据范围

当前内置数据来自 **《彩棠工作台项目进度表.xlsx》的 Sheet1**，按「层级」列解析结构。表内共 55 条阶段与任务记录：6 个阶段、6 个一级任务、43 个二级任务。细分计划指标只统计不含子项的 45 个任务，避免父子任务重复计数；其中 21 项已完成、5 项进行中、19 项未开始。总览为 3/6 阶段已完成，阶段完成率 50%。

计划开始与结束合并显示为「计划周期」，实际开始与结束合并显示为「实际周期」，日期以「08.04 — 08.11」格式呈现；日期与状态均保留 Excel 原样，不根据当天日期改写状态。斜杠「/」保持原样，空白不作推算。例如「新审批流设计」保留实际 10.08—10.16 和「进行中」。表尾两条不上线事项展示在「当前卡点和关键结论」中，并标为「关键结论」。原文件完整保留，可在更新记录下载。

初始报告基准为 2026-09-29，项目年份按原表的 2026 年设置。

## 每周更新

1. 在新版 Excel 中更新名称、主责部门、层级、计划开始时间、计划结束时间、实际开始时间、实际结束时间、阶段状态，保留这八列标题和阶段、一级任务、二级任务的层级结构。
2. 在页面上传 Excel，检查变更和报告基准日期后确认。导入器识别第一张工作表的八列表头，同时更新总览与详细计划；仍兼容旧版「项目计划」工作表。
3. 如只需更新管理阶段，可导入与当前阶段结构一致的 CSV。
4. 确认导入后，当前看板、当次计划快照及原文件会一起保存到浏览器 IndexedDB，刷新会恢复最近一次更新。未确认、取消、解析失败或存储失败的导入不写入历史。
5. 在「更新记录」下载当次上传的原文件。页面同时提供新版进度表和最初上传的 Excel 原件，每条记录只提供「下载原文件」。旧浏览器中的历史上传记录会保留，新版默认数据不会被旧版缓存覆盖。
6. 点击「导出汇报版」可另存当前看板，离线 HTML 内含新版和初始 Excel 原件，但不携带全部历史上传文件。JSON 快照用于保存和重新导入看板数据。

记录仅保存在创建记录的浏览器和网站地址下；清除网站数据、更换浏览器或设备不会同步保留。每个离线 HTML 文件的记录也独立保存。本版本不提供多人同步、服务端存储或外部 AI 服务。详细操作见 [`docs/使用说明.txt`](docs/使用说明.txt)。

## 文件

## 验证

`tests/history.spec.cjs` 覆盖新版 Excel 层级解析、六阶段总览、周期合并展示、原始日期与状态、甘特日期防重叠、搜索和折叠、计划甘特、新旧原文件下载一致性、旧缓存迁移、导入确认和刷新恢复、取消与无效文件、存储失败、北京时间标线，以及离线导出后的导入记录。需要 Node.js、Playwright 和 Microsoft Edge；安装 Playwright 后运行 `node --test tests/history.spec.cjs`。测试使用隔离浏览器，不写入日常使用的浏览器记录。
